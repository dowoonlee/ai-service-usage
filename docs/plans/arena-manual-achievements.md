# 수동 전투 업적과 칭호

숙련 훈장은 개별 펫의 기록이고, 전투 업적은 트레이너 전체의 전술 기록입니다. 일반 업적 6개와 히든 업적 2개를 제공합니다. 서버가 확정한 정상 경기만 공식 기록에 적립하며, 자동 맡기기를 포함한 수동전 규칙의 경기에서 판정합니다. 기존 ATB 경기는 대상이 아닙니다.

| 업적 | 조건 | 칭호 |
|---|---|---|
| 첫 지휘 | 첫 정상 승리 | 첫 지휘관 |
| 효과는 굉장했다 | 유리한 상성의 직접 공격으로 누적 10마리 처치 | 상성 전문가 |
| 선수 교체 | 자발적으로 교체한 펫이 반감 공격을 받고 바로 다음 턴 직접 공격으로 처치 | 교대의 명수 |
| 계획대로 | 적 속도 감소가 실제로 선후공을 뒤집은 턴에 선공 처치 | 전술 설계자 |
| 아직 한 발 남았다 | 궁극기를 쓸 수 있는 턴에 일반기로 처치한 후, 궁극기로 다른 상대 처치 | 한 발의 여유 |
| 두 가지 해답 | 같은 레인보우 펫으로 A·B 궁극기를 각각 유효하게 사용한 경기에서 승리 | 양면의 지휘관 |
| 마지막까지 | 내 생존 1마리·상대 3마리 이상인 상황에서 역전승 | 역전의 지휘관 |
| 함께 이룬 승리 | 체크포인트 한 번으로 생존 아군 3마리 이상을 실제 회복시키고 승리 | 팀의 수호자 |

마지막 두 업적은 히든입니다. 달성 전에는 업적 이름·조건·칭호를 숨기고, 실제 달성하면 공개합니다. 보상은 업적 도장과 리포트에서 장착하는 칭호이며 스탯·재화 보너스는 없습니다. 시즌이 바뀌어도 유지됩니다.

## 판정 세부

상성 처치는 기술 타입의 2배 상성인 직접 공격만 집계합니다. 지속 피해와 광역의 추가 피해는 대상별 상성을 다시 계산하지 않으므로 제외합니다. 한 경기 최대 5마리이며 누적 진행을 표시합니다.

교체 반격은 강제 출전이나 중립 공격으로는 달성할 수 없습니다. 실드가 흡수한 반감 공격은 유효한 피격으로 인정하지만, 교체한 펫이 쓰러지거나 처치가 한 턴 늦으면 해당 기회는 끝납니다.

속도 역전은 양측이 기술을 선택한 턴에 판정합니다. 현재 상대의 속도 감소 효과를 제거했을 때에는 내가 더 느리고, 효과를 적용한 상태에서는 내가 더 빨라야 합니다. 원래 빠른 펫이 이미 느린 적을 처치하거나 우선도가 다른 교체·방어를 사용한 경우는 제외합니다.

궁극기 보류는 게이지 10과 출전 펫의 레인보우 해금을 함께 확인합니다. 일반기로 처치한 상대와 궁극기로 처치한 상대는 달라야 합니다. 궁극기의 광역 처치도 인정하며 팀 공용 게이지이므로 같은 펫이 두 처치를 모두 수행할 필요는 없습니다.

두 가지 해답은 기존 공식 숙련 기록의 `original_wins > 0 AND alternate_wins > 0`을 같은 펫에서 확인합니다. 서로 다른 펫의 A·B 실적을 합치지 않습니다. 분기별 문양은 기존대로 각 5승이고 이 업적은 각 1승이므로 서로 다른 이정표가 됩니다.

역전 상황은 턴 시작, 행동 완료, 양측 턴 종료 효과 처리 완료 시점에 관측합니다. 동시 지속 피해를 한 팀씩 계산하는 도중의 일시적인 인원수로 판정하지 않습니다. 단체 회복은 실제 HP가 증가한 생존 펫 수를 세므로 만피·기절 대상은 포함하지 않습니다.

첫 지휘·역전·단체 회복·분기 실적에는 승리가 필요합니다. 나머지 전술 기록은 정상 종료한 패배·40턴 무승부에서도 인정합니다. 항복·만료·운영 취소·대여 튜토리얼은 모두 제외합니다. 미완료 경기는 최종 확정 전까지 적립하지 않습니다.

## 공식 기록과 연습 미리보기

공식 업적은 팀 전원의 보유 정보가 서버에서 검증된 경기만 적립합니다. 일반 업적은 레인보우가 없어도 달성할 수 있으므로, 레인보우 훈장 대상 목록과 별도로 `achievementsEligible`을 경기 시작 시 서버가 동결합니다. 클라이언트가 보낸 달성 결과나 승수는 받지 않습니다.

앱은 연습 기록을 별도로 저장해 조건을 충족했는지 미리 보여줍니다. 같은 경기 ID 재도전은 중복 집계하지 않습니다. 연습 달성은 공식 칭호를 해금하지 않습니다. 공식 기록 캐시는 계정별로 분리하고, 리포트의 칭호 해금은 공식 캐시만 참조합니다.

## 서버 저장과 배포

`20261025084647_manual_arena_achievements.sql`을 기존 수동전 마이그레이션 다음에 적용합니다. 업적 진행·해금 시각과 경기별 적립 영수증을 저장합니다. 기존 경기 종료 RPC가 최종 상태와 펫 숙련 기록을 반영한 뒤 요청 영수증을 삽입할 때, 같은 트랜잭션 안에서 업적을 집계합니다. 따라서 A·B 두 번째 승리 직후 바로 분기 업적을 얻고, 응답 재전송으로 중복 적립되지 않습니다.

앱의 서버 상태 조회가 진행도와 해금 목록을 반환합니다. 업적 목록은 아레나 연습전과 수동전 준비·결과 화면에 있고, 공식 칭호는 리포트에서 장착할 수 있습니다. 운영 서버 적용과 보유 검증 자료 연결은 [구현과 운영 준비](arena-manual-implementation.md)를 따릅니다.
